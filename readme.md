# MyDalamudPresets

FFXIVのDalamudプラグインで使用するプリセット、設定、外部スクリプトの参照先、使い方のメモをまとめています。

## プラグインから探す

| プラグイン・分類 | 収録内容 |
| --- | --- |
| [Splatoon](splatoon/README.md) | コンテンツ別の表示プリセット、スクリプトの参照先・設定、補足メモ |
| [Waymark](waymark/README.md) | 拡張・コンテンツ別のインポートデータと配置画像 |
| [Yes Already](Yes_Already/README.md) | 確認ダイアログに対応する正規表現 |
| [Pandora](pandora/README.md) | 採集に関する設定項目と補足メモ |
| [Island Sanctuary Automation](island_sanctuary_automation/README.md) | 素材別の採集ルート |

各一覧から収録ページへ移動できます。Splatoonの一覧では、外部記事への案内のみのページと、設定未収録の構想メモを明記しています。

## 設定の利用方法

1. プラグインの一覧から、対象コンテンツ・用途のページを開きます。
2. 対応言語、攻略方式、ロール、前提となるスクリプト、注意事項を確認します。
3. 必要なコードブロックの内容をコピーします。前後の説明やコードフェンス（バッククォート）は含めません。
4. 各ページの手順とプラグインの対応する設定画面に従って適用します。スクリプトURL、スクリプトの描画設定、レイアウトのプリセットは、それぞれの説明を確認して使用してください。
5. ロールや表示項目など、ページ内で指定されている個別設定を確認します。

Waymarkは対象コンテンツ・フェーズ・攻略方式を見出しで確認し、同じ節の画像とインポートデータを参照してください。画像がない項目もあります。

## 注意事項

- 古いプリセットや、現在の環境では動作未確認の設定も含まれます。更新日だけで動作確認済みとは判断しないでください。
- 日本語のみ対応するトリガー、特定の攻略方式・ロールを前提にした設定があります。各ページの注意事項を優先してください。
- Splatoonの描画方式変更に伴う注意事項や、塗りつぶしなどの調整が必要なケースは、該当ページに記載しています。[7.0の変更に関するメモ](splatoon/memo.md)も参照してください。
- 既存設定を置き換える前に、必要な設定をエクスポートするなどして控えを残してください。
- 外部記事やスクリプトは参照先で更新される場合があります。このリポジトリの記述は、常に最新の動作を保証するものではありません。

## 新しい設定を追加する

[追加・更新ガイド](CONTRIBUTING.md)に、配置方針、記述項目、確認事項をまとめています。

既存プラグインには用途・コンテンツ単位のページを追加し、該当プラグインの一覧へリンクを追加します。新しいプラグインはルート直下に専用ディレクトリとREADMEを作り、この表に追加してください。Lifestreamは今後の追加候補であり、現時点では設定を収録していません。
